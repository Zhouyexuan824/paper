# Paper Atlas · 论文关系网

个人论文工作台，以 Paperline 的检索与分区整理界面作为首页，并接入 Paper Atlas 的持久化 3D 论文星图。支持真实学术检索、一键整理并绘图、Baseline / 后续 / 同任务论文分区、千问 / DeepSeek / MiniMax 摘要分析、引用扩展、个人笔记和图谱连线编辑。

## 运行

需要 Node.js 22.13 以上。

```bash
npm install
cp .env.example .env
# 在 .env 中配置千问、DeepSeek 或 MiniMax API key
npx wrangler d1 migrations apply DB --local --config wrangler.local.jsonc
npm run dev
```

浏览器打开开发服务器提示的地址。点击“登录工作台”进入 Sites 本地开发身份。生产部署通过 Sites 的私有站点入口识别登录用户。

`.env` 已忽略，不能提交。生产密钥由 Sites secret 保存，不下发浏览器。AI 提供商按千问、DeepSeek、MiniMax 的顺序选择第一个已配置项。

## 操作

1. 首页保留 Paperline 的工作流：输入题名，核对候选，点击“整理并绘图”。
2. 整理结果按研究摘要、Baseline 与前置方法、重要后续、同任务方法、代码和数据集分区显示，并同步到个人图谱。
3. 默认进入“关系图谱”：拖动空白处旋转 3D 星图，滚轮缩放，点击星点查看信息；选择任意节点后可用 AI 继续扩展。
4. “AI 分析摘要”使用已配置的千问、DeepSeek 或 MiniMax 提取模块、领域、方法及数据集，保留摘要中的直接证据。
5. “展开引用与相关论文”每次返回最多 14 篇参考文献、6 篇后续引用及多源题名相关候选。此为有界的一度展开，不代表全部文献已载入。
6. 点击“连线”，再点击目标节点即可添加关系；点击已有连线可编辑类型、说明、证据、来源或删除。
7. 右侧记录摘要、实验结构、代码、数据集 URL 与私人笔记。手动修改通过独立覆盖层保存，不被自动分析覆盖。
8. 可拖动节点、自动旋转、全屏查看、筛选实体类型、导出 JSON。论文库和节点信息以浮层按需展开，让星图保留主要屏幕空间。

## 数据和准确性

- 只抓取摘要、书目元数据与引用索引，不下载 PDF、不绕过付费墙。
- API 查询 arXiv 与 OpenAlex，失败时使用 Crossref；引用支持 OpenAlex 逐篇查询、Crossref、Semantic Scholar 与 arXiv 公开参考文献列表回退。重复元数据缓存一天。arXiv HTML 只用于书目与引用提取，不作为 AI 实验结论的依据。
- 所有个人节点和关系按平台提供的稳定用户 ID 隔离在 D1，查询不接收前端指定的用户 ID。
- DOI、arXiv ID、标准化题名用于论文合并；非论文实体结合标签去重。不用相似题名强行认定同一论文。
- AI 输出只有在证据确实是输入摘要的连续片段时才写入关系，仍标为“待核验”。关键词出现本身不能证明关系，所以不会自动升为来源支持。
- 模型输出不被用作 SQL、HTML 或可执行代码；AI 不生成外部 URL。代码链接仅从摘要直接提取。
- 仅已核验的常见方法可直接映射到论文；其余方法保留为实体，用户点击“查找对应论文”后核对候选。
- OpenAlex 的引用边仅表示索引记录，不表示 baseline、实现基础或借鉴。题名相关性仅为探索候选。
- 手动删除的连线保留屏蔽标记，后续自动展开不恢复；人工修改的关系不被自动重写。
- 不保证只靠摘要能识别完整实验设置、baseline、消融实验或所有平行工作。这些内容支持手动补充来源。
- 初始数据集链接来自作者仓库：YimianDai/sirst、RuiZhang97/ISNet、YeRen123455/Infrared-Small-Target-Detection。SIRST 作者不建议使用 NUAA-SIRST 称呼，示例保留论文中的叫法并注明正式名称。

## 验证

```bash
npx tsc --noEmit
npm run build
node scripts/smoke.mjs
```

Smoke 脚本针对本地开发服务验证未登录拒绝、持久化、节点存在性、URL 校验、连线创建/编辑/删除、自环拒绝和跨源请求拦截。需要先初始化本地数据库。会创建并清理一条测试关系、恢复原笔记。

已进行真实 arXiv/OpenAlex 检索与引用展开；AI 集成测试需要本地配置任一提供商的密钥。实现了可选 WebMCP 的读取图谱、搜索论文、加入论文工具。

## 结构

- `app/workspace.tsx`：主工作台与交互。
- `app/graph-canvas.tsx`：基于 `react-force-graph-3d` 的 WebGL 星图、镜头聚焦、移动和缩放。
- `app/api/`：带用户隔离的后端路由。
- `lib/sources.ts`：学术数据源、规范化与检索。
- `lib/ai.ts`：千问 / DeepSeek / MiniMax 兼容调用、JSON 校验、证据匹配。
- `lib/server.ts`：D1 访问、人工覆盖层、去重、缓存和限流。
- `db/schema.ts` 与 `drizzle/`：数据库定义和版本化迁移。

本地个人数据在 `.wrangler/`，不上传；线上使用独立 D1 数据库。站点默认为所有者私有。

## 中心扩展与引用修复

选择任意论文、模块、领域或数据集，点击“以此为中心 · AI 扩展”。后台根据节点与相邻研究规划检索，核对实际返回的候选论文，再让当前 AI 提供商筛选最多5篇相关论文。模型不能创建不存在于检索结果中的论文 ID。论文中心还同时提取摘要关系和展开引用。

中心视图把选中节点置于画布中央、相邻节点分环排列；返回完整图谱后恢复原布局。中心视图中的拖动只影响当前视图，不覆盖全图手动坐标。原图谱、笔记、人工连线和删除屏蔽记录保留。

引用状态按参考文献、后续引用、相关检索分别报告。所有来源失败时返回错误，避免出现“0条但已添加”的假成功；部分失败保留已取得的结果。OpenAlex 空引用列表继续尝试其他来源，不当作论文无引用的证据。可通过“检查数据源状态”查看当前来源情况。此检查只查询预定义的公开论文，不读取个人图谱。

可选 `OPENALEX_API_KEY`、`SEMANTIC_SCHOLAR_API_KEY` 仅在服务器配置；不要求它们才运行。

回归验证：`node --experimental-strip-types scripts/regression.mjs` 覆盖列表接口失败、逐篇回退、独立 Crossref 回退、空索引补查、全源失败、摘要源失败不阻断引用、任意节点居中与布局隔离。

### 聚焦阅读与探索反馈

- 默认仅显示中心节点的直接关系，支持按参考文献、被引用、方法/领域、数据集与相关工作筛选，也可隐藏待核验候选。
- 聚焦图先显示 24 个相邻节点，可逐批展开；视图筛选不删除数据库中的任何关系。双向/多重关系用分开的曲线显示。
- 返回按钮沿本次浏览路径回退。新增论文留在自己的关系网，后台扩展完成不会抢走当前正在阅读的其他节点。
- 右侧本次探索结果按来源分别展示成功、空缺、失败与重试。该结果卡仅属于本次页面会话，论文、关系和笔记仍持久保存。
- 视图逻辑回归：`node --experimental-strip-types scripts/view-regression.mjs`。

### 智能研究脉络

“分析研究脉络”支持输入具体研究目标，按中心摘要规划检索，补充候选摘要，再逐篇独立比较。模型通过句子 ID 选择两边的摘要依据；服务端校验来源、候选 ID、时间关系，拒绝虚构引文或未经证实的直接 baseline。

分析包含中心问题、技术路线、作者声称的改进、按顺序推荐的论文、具体差异、阅读问题、待核验事项和下一步建议。报告保存在节点的 JSON 数据中，随个人图谱持久保存，无新增表或迁移。研究视图聚焦本次推荐，原有文献和手动关系保留；原始引用由独立按钮展开。局限：尚未分析全文，不能据此确认完整实验设置或全部 baseline。

验证：`node --experimental-strip-types scripts/research-regression.mjs` 检查证据、ID、概念、时间和缺摘要的边界；`node scripts/research-integration.mjs` 会调用配置的 AI，并检查 SAMamba 的技术来源识别、双边引文、保存重读及个人笔记保留。
